# features

- `render`ゴール
  - 指定した形式ごとに、入力ファイルと同じ名前のファイルを書く
  - 入力ファイルのアウトラインが、出力に描画される
  - 拡張子のない入力ファイルは、その名前のまま出力ファイルの名前になる
  - 出力先のフォルダーがなければ作る
  - カードの幅の上限を、パラメーターで変えられる
  - 失敗
    - 未知の形式を指定すると、ビルドが失敗する
    - 倍率が正でなければ、ビルドが失敗する
    - 入力ファイルがなければ、実行エラーになる
    - 描画に失敗すると、実行エラーになる
- 出力形式
  - 形式の名前は、大文字と小文字を区別しない
  - 未知の形式の名前は、受け付けない
- 描画
  - HTML
    - スタイルを含む、単独で開けるHTMLページになる
    - ページのタイトルは、マップのタイトルをエスケープしたものである
    - 日本語のカードが、文字化けせずに出力される
    - カードの幅の上限を指定しなければ、240pxになる
    - カードの幅の上限を変えられる
  - 画像
    - SVGは、SVG文書になる
    - PNGは、PNG画像になる
    - PNGの幅は、倍率に比例する
    - カードの幅の上限を狭くすると、長い文のカードが折り返され、画像が狭くなる
    - 大きすぎる画像は、描画の失敗になる
  - 倍率は、正の有限の数でなければならない
  - カードの幅の上限は、正の有限の数でなければならない
- ネイティブライブラリ
  - OSとアーキテクチャから、クラスパス上のライブラリの場所が決まる
  - 対応していないOSやアーキテクチャでは、ライブラリの場所が決まらない
  - ライブラリの内容を、指定した名前のファイルに書き出す
  - 同じ内容のライブラリは、書き直さずに前のコピーを使う
  - 内容の違うライブラリは、別の場所に書き出す
